# Jui-peng · Pragma engineering

**English** · [繁體中文](#繁體中文)

An engineering space for **Pragma**. Projects are organized by purpose and remain
in separate repositories, with their own versions and maintenance responsibilities.

| Area | Focus |
| --- | --- |
| Websites & documentation | Site interfaces, product guides and shared presentation components |
| Community services | Publishing, community interactions and content rendering |
| Model services | Model access, gateways and service integrations |
| Operations | Release verification, service status and maintenance procedures |

This public page introduces the project areas. Source repositories and the member
directory have their own access controls; their absence here does not imply that
a service is unavailable or that its source is public.

Research methods and academic tools are maintained on
[Ruipeng LU's personal profile](https://github.com/lzhs1995).
